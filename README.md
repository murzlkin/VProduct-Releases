# Vproduct

Windows-клиент для VLESS и WireGuard с сетевым ядром sing-box.

## Скачать

[Скачать Vproduct.exe](https://github.com/murzlkin/VProduct-Releases/releases/latest/download/Vproduct.exe)

[Все версии и изменения](https://github.com/murzlkin/VProduct-Releases/releases)

## Запуск

1. Скачайте Vproduct.exe из Releases и сохраните в отдельной папке.
2. Запустите программу. Требуются Windows 10/11 x64 и .NET Framework 4.8.
3. Нажмите «Добавить сервер» и вставьте VLESS-ссылку или выберите клиентский WireGuard-файл .conf.
4. Выберите режим и нажмите «Подключить». TUN запросит права администратора.
5. При первом подключении программа скачает sing-box 1.14.4 с GitHub и проверит SHA-256. Ядро можно также скачать из [официального релиза sing-box](https://github.com/SagerNet/sing-box/releases/tag/v1.14.4), распаковать и указать через «Выбрать ядро».

Vproduct.exe запускается без установки. Исполняемый файл пока не подписан, поэтому Windows SmartScreen может показать предупреждение.

## Маршрутизация

Наборы Main и RU можно редактировать и дополнять своими наборами. RU направляет домены .ru и .рф напрямую, прочий внешний трафик — через выбранный сервер.

Условия поддерживают домен с поддоменами, точный домен, IP/CIDR, имя процесса (например telegram.exe) и полный путь к .exe. Применяется первое совпавшее правило. Правила приложений работают в TUN.

Профили сохраняются на компьютере и шифруются Windows DPAPI для текущего пользователя.
